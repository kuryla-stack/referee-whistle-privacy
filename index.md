# Privacy policy

Effective date: 26 September 2026

Referee: Whistle and Laws is an offline application for football officials. This policy explains what the application does with information entered by the person using it.

## Information stored

The application stores preferences such as onboarding completion, theme, haptics and drill timer settings. It also stores the person's drill progress, law mastery, streak history and match-log entries. Match-log entries may include competition, level, team names, incident counts and notes entered by the person using the application.

## Where information is stored

Information is stored locally on the device using the platform's local preferences storage. The application does not send this information to the developer, an analytics service, an advertising service, a cloud account or a remote server. The application does not require an account and does not request network access.

## Sharing and retention

The application does not sell, share or disclose stored information. Information remains until the person deletes it using Reset progress, clears application data, or removes the application from the device. Device backups and operating-system behavior are outside the application's control.

## Children

The listed target audience is adults aged 18 and over. The application does not knowingly collect personal information from children.
